Perintah CLI

Salin atau unduh perintah siap tempel ke terminal perangkat.

Cisco IOS

Untuk router atau switch Cisco IOS: CPU, memory, dan traffic interface.

terminal length 0
show processes cpu | include utilization
show processes cpu history
show memory statistics
show interfaces

Cisco IOS XE

Untuk router ISR/ASR atau switch Catalyst yang menjalankan IOS XE.

terminal length 0
show plat soft stat contr br
show processes cpu | include utilization
show processes cpu history
show interfaces

Jalankan dari privileged EXEC (prompt #). Untuk IOS XE, command platform bergantung model dan versi. Simpan output terminal lengkap lalu impor file outputnya, bukan file command dari tombol.
